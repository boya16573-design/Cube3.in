# Cube3 Full-Stack v1

Includes Supabase Auth, Creator/Brand roles, profiles, campaigns, applications, dashboards, RLS, and an Express API.

1. Run `supabase/schema.sql` in Supabase SQL Editor.
2. Copy `.env.example` to `.env` locally and fill the keys.
3. Run `npm install` then `npm start`.
4. Set the same environment variables in Render.
5. In `js/config.js`, replace the placeholder Supabase URL/key with your project's publishable values.

Never put `SUPABASE_SECRET_KEY` in browser code or GitHub.
