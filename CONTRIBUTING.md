# Contributing to Math Canvas

Thank you for helping. You do not need permission to start.

## How a change gets in

1. **Fork** this repo (the Fork button on GitHub).
2. Make a branch in your fork and make your change.
3. Test it in a real browser (see below).
4. Open a **pull request** and say what you changed and why.
5. The owner reviews it. Only the owner merges into `main`, and the site updates after that.

## Good first changes

- Fix a bug you found. Say how to reproduce it.
- Add a template, a scene, a graph preset or a sticker.
- Improve a label or message so a beginner understands it.
- Make something work better on a phone.

## Rules

- **Keep real maths real.** If a feature shows an equation, the equation must match what the code does. Do not add a formula that is only decoration.
- **Be honest about limits.** Do not claim a result is "perfect" or "AI". Show the measurement instead.
- **One file stays one file.** The app should still run from `index.html` with no build step and no server.
- **No tracking, no sign-in, no uploads.** Files stay in the person's browser.
- **No secrets.** Never commit keys, tokens or passwords.
- **Keep it readable.** Plain words in the interface. Beginners and social-media creators are the audience.

## Testing

Before you open a pull request, check these in a current Chrome or Firefox, and on a phone if you can:

- Add a photo, change a few settings, and check that nothing shows red errors.
- Open the Check tab and confirm the equations still match.
- Export an image and a short video. Open them.
- Reload the page and confirm your project is still in Projects.

## Reporting a problem

Open an **Issue**. Include your browser and device, what you did, what you expected, what happened, and a screenshot if you can.
